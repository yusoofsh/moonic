# Moonic

**A VSCode theme that doesn't compromise.**

Moonic takes the best parts of [Electronic Dawn](https://marketplace.visualstudio.com/items?itemName=NoahRaskin.electronic-dawn-theme), [Catppuccin Noctis](https://marketplace.visualstudio.com/items?itemName=AlexDauenhauer.catppuccin-noctis), and [Maron Themes](https://marketplace.visualstudio.com/items?itemName=KainNhantumbo.maron-themes)—then makes opinionated decisions about what actually works. The result? Colors that don't fight for attention, syntax highlighting that makes sense, and a palette that's easy on the eyes whether you're debugging at 2am or reviewing PRs over morning coffee.

![Preview](/images/preview.jpeg)

## Why Moonic?

- **Carefully curated colors** — Every shade chosen for contrast, readability, and eye comfort
- **Three distinct variants** — Light, Primary (dark), and Secondary (dark) for different moods and lighting
- **Opinionated by design** — Strong decisions on what matters: clear syntax, readable docs, comfortable UI
- **Best-of-breed blend** — Combines proven color choices from beloved themes, refined through real-world use

## Variants

- **Moonic Light** — Bright and clean for daylight coding
- **Moonic Primary** — Rich dark theme for focused work
- **Moonic Secondary** — Alternative dark variant for variety

## Installation

1. Open VSCode
2. Go to Extensions (`Cmd+Shift+X` / `Ctrl+Shift+X`)
3. Search for "Moonic"
4. Click Install
5. Select your preferred variant: `Code > Preferences > Color Theme > Moonic`
